    <h1>GUI Maker</h1>

    <ul>
        <li>
            This is the official Github Repository for 
            <a href="https://modrinth.com/datapack/gui-maker" target="_blank">GUI Maker</a>.
        </li>
        <li>
            All Work-in-Progress/Unstable Releases are uploaded here. 
            Stable releases are uploaded on Modrinth!
        </li>
        <li>
            The datapack uses 
            <a href="https://github.com/gibbsly/gu/tree/main" target="_blank">GU Library</a> (embedded).
        </li>
    </ul>

    <h3>What's Different?</h3>

    <ul>
        <li>
            This re-written version of the datapack cleans out messy code, 
            allows for easy readability and optimized execution/usage.
        </li>
        <li>
            The datapack was rewritten to introduce a foundation to create special items, 
            some of which are: Toggle Buttons and Item Holder.
        </li>
        <li>
            The datapack now also has a cache system, to save changes to every player's 
            particular cache stack. (Hence the use of 
            <a href="https://github.com/gibbsly/gu/tree/main" target="_blank">GU</a>)
        </li>
    </ul>
