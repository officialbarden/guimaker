<h1>GUI Maker</h1>

<ul>
    <li>
        This is the official Github Repository for 
        <a href="https://modrinth.com/datapack/gui-maker" target="_blank">GUI Maker</a>.
    </li>
    <li>
        All Work-in-Progress / Unstable releases are uploaded here. 
        Stable releases are uploaded on Modrinth.
    </li>
    <li>
        The datapack uses 
        <a href="https://github.com/gibbsly/gu/tree/main" target="_blank">GU Library</a> (embedded).
    </li>
</ul>

<h3>What's Different?</h3>

<ul>
    <li>
        This rewritten version of the datapack cleans messy code, 
        improves readability, and optimizes execution and usage.
    </li>
    <li>
        The datapack was rewritten to introduce a foundation for creating special items, 
        such as Toggle Buttons and Item Holder.
    </li>
    <li>
        The datapack now includes a cache system to save changes to each player's 
        cache stack (hence the use of 
        <a href="https://github.com/gibbsly/gu/tree/main" target="_blank">GU</a>).
    </li>
</ul>
